# Security Monitoring with Splunk

## 📌 Project Overview

This project was completed as a cybersecurity SOC analyst capstone project. It simulates the activities of a Tier 1 SOC Analyst responsible for monitoring, detecting, and investigating security events in a hybrid cloud environment.

Splunk was used as the primary Security Information and Event Management (SIEM) platform to collect, search, analyse, and correlate security logs from multiple sources.

## 🎯 Project Objectives

- Monitor security events using Splunk
- Analyse logs from multiple security data sources
- Identify suspicious activities and potential security threats
- Investigate security alerts and events
- Correlate events across different log sources
- Document investigation findings
- Recommend appropriate security responses

## 🔎 Investigation Process

The investigation followed a typical Tier 1 SOC Analyst workflow:

1. Ingested security logs into Splunk
2. Searched and filtered security events
3. Identified suspicious activity
4. Investigated relevant events and timestamps
5. Correlated information across different data sources
6. Analysed indicators of potential compromise
7. Documented investigation findings
8. Provided recommended security actions
